# QuizAi 비즈니스 규칙

이 문서는 코드보다 먼저 합의되어야 하는 서비스 정책을 기록합니다. 아래 내용은 초기 예시이며, 실제 운영 정책이 정해지면 구체적인 숫자와 예외 조건을 업데이트합니다.

## 핵심 사용자 가치

사용자는 긴 기술 글이나 유튜브 영상을 모두 소비하지 않아도, URL 하나로 핵심 내용을 퀴즈 형태로 학습할 수 있어야 합니다.

## 사용자 유형

### 게스트

- 로그인 없이 퀴즈 생성을 시도할 수 있습니다.
- 생성 결과를 임시로 풀 수 있습니다.
- 저장, 마이페이지 조회, 장기 보관 기능은 제한될 수 있습니다.

### 회원

- OAuth 로그인을 통해 가입합니다.
- 생성한 퀴즈를 저장하고 다시 조회할 수 있습니다.
- 닉네임을 설정하거나 변경할 수 있습니다.

## 퀴즈 생성 규칙

- 입력 URL은 지원 가능한 콘텐츠여야 합니다.
- 지원 대상 예시:
  - 기술 블로그 글
  - 유튜브 영상
- 지원하지 않는 URL 또는 본문 추출이 불가능한 URL은 사용자에게 실패 사유를 안내합니다.
- 문제는 기본적으로 객관식 형식을 사용합니다.
- 각 문제는 질문, 선택지, 정답, 해설을 포함해야 합니다.
- 앞 문제를 풀어야 다음 문제로 넘어가는 흐름을 유지합니다.

## 문제 수 정책

초기 예시:

- 최소 문제 수: 3개
- 기본 문제 수: 5개
- 최대 문제 수: 10개

문제 수 제한은 비용, 응답 시간, 사용자 경험을 함께 고려해 조정합니다.

## Rate Limit 정책

Gemini API 비용과 서버 부하를 보호하기 위해 퀴즈 생성 요청에는 제한을 둡니다.

초기 예시:

- 같은 사용자 또는 같은 IP의 짧은 시간 내 반복 생성 요청을 제한합니다.
- 제한 초과 시 HTTP 429와 사용자 친화적인 메시지를 반환합니다.
- Rate Limit 기준 변경 시 백엔드 구현과 이 문서를 함께 갱신합니다.

## 퀴즈 저장 및 공개 범위

초기 예시:

- 회원은 생성한 퀴즈를 저장할 수 있습니다.
- 퀴즈는 공개 또는 비공개 상태를 가질 수 있습니다.
- 비공개 퀴즈는 생성자만 조회할 수 있습니다.
- 공개 퀴즈는 게시판 또는 목록 화면에 노출될 수 있습니다.

## 인증 및 계정 규칙

- OAuth 제공자별 계정은 내부 사용자 계정과 연결됩니다.
- 현재 운영 로그인 제공자는 Google이며, Kakao 로그인 버튼은 추후 지원 예정 안내만 표시합니다.
- 탈퇴 또는 비활성화된 사용자는 보호된 API를 사용할 수 없습니다.
- 닉네임은 중복될 수 없습니다.
- 닉네임 변경 정책이 생기면 횟수 제한과 금지어 정책을 명시합니다.

## AI 응답 품질 규칙

Gemini 응답은 그대로 신뢰하지 않고 서버에서 검증합니다.

검증 예시:

- JSON 파싱 가능 여부
- 문제 수 일치 여부
- 선택지 개수 충족 여부
- 정답이 선택지 중 하나인지 여부
- 질문 또는 해설이 비어 있지 않은지 여부

검증 실패 시 재시도하거나 실패 상태로 처리합니다. 재시도 횟수는 비용과 응답 시간을 고려해 제한합니다.

## 실패 처리

사용자에게 내부 예외나 외부 API 세부 오류를 그대로 노출하지 않습니다.

실패 유형 예시:

- URL 본문 추출 실패
- 유튜브 다운로드 또는 분석 실패
- Gemini API 실패
- Rate Limit 초과
- 인증 만료
- 저장 대상 없음

### 비동기 Job 복구

- 퀴즈 생성 Job은 Redis에 30분 동안 보관합니다.
- Backend 종료 시 새 Job 수락을 중단하고 진행 중인 Job이 끝날 때까지 최대 120초 대기합니다.
- 서버 장애나 강제 종료 후 20분 이상 `PROCESSING` 상태인 Job은 정상 완료 가능성이 낮은 것으로 판단해 `FAILED`로 전환합니다.
- 복구된 실패 응답에는 서버 재시작 또는 처리 시간 초과라는 사용자용 메시지를 제공하며 내부 예외는 노출하지 않습니다.

## 변경 시 주의사항

아래 규칙을 바꾸는 경우 코드, 테스트, API 문서를 함께 확인합니다.

- 문제 수 제한
- 게스트/회원 권한 차이
- 공개/비공개 조회 정책
- Rate Limit 기준
- AI 응답 검증 기준
- 인증 쿠키 또는 JWT 만료 정책
- Redis Job TTL 또는 오래된 Job 복구 기준
